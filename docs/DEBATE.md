## Brand Strategist

### รอบ 1

- **Headline** "PHP Developer ที่เปลี่ยนโจทย์ธุรกิจให้เป็นเว็บที่ใช้งานได้จริง" ชัดและบอกคุณค่าแล้ว แต่คำว่า "ใช้งานได้จริง" เป็นคำที่ dev ทุกคนใช้ จึงยังไม่มีอะไรให้จำ
- **Tagline** อัดสามเรื่อง (ประสบการณ์ + กำลังเรียน + AI) ไว้ในบรรทัดเดียว คำว่า "ขยายสู่" ฟังเหมือน "ยังไปไม่ถึง" ทำให้ HR เชื่อน้อยลง และยังไม่ไปทางเดียวกับ headline: headline พูดเรื่องคุณค่าที่ให้ธุรกิจ แต่ tagline พูดเรื่อง skill ของตัวเอง
- **Audience:** ต้องเลือกกลุ่มหลักกลุ่มเดียว เห็นด้วยกับ Brainstorm ว่า HR คือกลุ่มหลักและลูกค้าคือกลุ่มรอง ตัดมือใหม่ PHP ออกจากหน้าแรกแล้วเก็บไว้ทำ Blog ในภายหลัง
- **ข้อเสนอ:**
  1. Tagline เปลี่ยนจากน้ำเสียง "กำลังไป" เป็น "ทำอยู่": "5+ ปี สร้างเว็บองค์กรและระบบหลังบ้านด้วย PHP · Laravel · ทำงานร่วมกับ AI agents" ส่วน "Full-stack" ย้ายไปไว้ใน Bio
  2. Headline เติม "และดูแลต่อได้ยาว" เพื่อสร้างความต่าง (วลีนี้มีอยู่ใน Bio แล้ว)
  3. CTA ท้าย Bio พูดกับกลุ่มหลักตรง ๆ: "กำลังหา PHP/Laravel Developer หรืออยากได้ระบบหลังบ้านสักตัว — ส่งข้อความหาผมได้เลยครับ"
- **จุดยืนที่คาดว่าจะถูกค้าน:** จะไม่ตัด "ดูแลต่อได้ยาว" แม้ UX จะบอกว่ายาว เพราะแก้ด้วย typography ได้ และจะไม่ทิ้ง AI agents เพราะเป็นจุดต่างเพียงข้อเดียว (เขียนแบบ "ทำงานร่วมกับ" ไม่ใช่ "ให้ AI ทำ")

### รอบ 2 (ตอบ UX + Devil)

- **รับ:** tagline แบบของ UX ถ้าเจ้าของยืนยันสถานะเปิดรับงาน · Home สั้น แล้วเล่าเรื่องต่อที่ About · เมนู 4 รายการ · แยก Skills ออกจาก Interests · ไม่ render "—" ของ LinkedIn
- **รับจาก Devil:** R1/R3 ไม่ต้องโชว์ Gmail ตรง ๆ · R2 เลื่อน Guestbook ไป Later · R6 · R8 · ตัด "Full-stack"
- **รับครึ่งเดียว R4:** "5+ ปี" เป็นข้อเท็จจริง ไม่ใช่ overclaim แต่ยอมรับว่าต้องมีหลักฐาน จึงเสนอให้ **case study 1 ชิ้น (ไม่ระบุชื่อลูกค้า)** เป็น Must
- **ค้าน:** การตัด AI agents ทิ้งทั้งหมด → เปลี่ยนถ้อยคำเป็น "เว็บนี้ผมออกแบบและตรวจทุกส่วน โดยใช้ AI agents ช่วยพัฒนา" ให้ชัดว่าใครคุมงาน และไม่ชี้ไปที่คอร์ส
- **ค้าน R7 ที่ให้ซ่อนฟอร์ม:** ถ้าซ่อนแล้วไม่มี CTA จะแย่กว่า จึงเลือกแนวทาง UX รอบ 1 คือเก็บข้อความที่ผู้ใช้พิมพ์ไว้และแสดงช่องทางสำรอง
- **ยืนยันเดิม:** headline ต้องมี "ดูแลต่อได้ยาว" · About ไม่จำเป็นต้องครบ 4 ย่อหน้า

## UX Critic

### รอบ 1

- **Interests ยังไม่พร้อม:** มีแค่ 4 ป้ายคำ ถ้าทำเป็นการ์ด การ์ดจะว่าง ควรเพิ่มบรรทัดเดียวต่อข้อว่า "ทำอะไรกับมัน" และถ้ายังไม่แก้ L2 หน้านี้จะแสดงแค่การ์ดเดียว ดูเหมือนเว็บพัง
- **Contact:** `linkedin: —` จะ render เป็นขีดลอย ๆ · ฟอร์มที่ตอบ 501 ไม่มีทางสำรอง ถ้าผู้ใช้พิมพ์ข้อความยาวแล้วข้อความหาย จะเสียความเชื่อใจทันที
- **Skills อยู่ใน Must แต่ PROFILE ไม่มี section นี้** และสำหรับ HR แล้ว Interests ไม่ใช่ Skills
- **จุดที่ผู้เยี่ยมจะสับสน:** HR ดู 10 วินาทีแล้วไม่รู้ว่าเจ้าของ "เปิดรับงานไหม" และ "5+ ปี" ไปอยู่บรรทัดรอง · ลูกค้าไม่เห็นหลักฐานงาน · หน้า About กับ Interests มีเนื้อหาทับกัน
- **IA / microcopy:**
  - เมนู: `หน้าแรก · เกี่ยวกับผม · ทักษะและความสนใจ · ติดต่อ` และย้าย Guestbook ไป footer
  - Hero: headline + `5+ ปี · PHP/Laravel · เปิดรับงานประจำและฟรีแลนซ์` (ต้องให้เจ้าของยืนยัน) · CTA หลัก `ติดต่อผม` · CTA รอง `ดู GitHub` วางเหนือ fold
  - ข้อความเมื่อได้ 501: "ระบบส่งข้อความยังไม่พร้อม ส่งอีเมลหาผมตรงได้เลย ข้อความที่คุณพิมพ์ยังอยู่ในช่อง" (ห้ามล้างฟอร์ม)
  - ข้อความเมื่อส่งสำเร็จ: "ได้รับแล้วครับ ปกติตอบภายใน 1–2 วันทำการ"
- **จุดยืน:** Home แสดงแค่ headline + 1 บรรทัด + CTA แล้วเล่าเรื่องที่ About · อีเมลเป็นช่องทางหลักที่เห็นเสมอ ฟอร์มเป็นทางรอง

### รอบ 2 (ตอบ Brand + Devil)

- **รับ:** tagline ของ Brand ที่ขึ้นต้นด้วย "5+ ปี" · ตัดมือใหม่ออกจาก Home · CTA ปิดท้าย แต่ย่อสำหรับมือถือเป็น "กำลังหา PHP/Laravel Dev หรืออยากได้ระบบหลังบ้าน? ทักผมได้เลย" + ปุ่ม `ส่งข้อความ`
- **ค้านครึ่งหนึ่ง "และดูแลต่อได้ยาว":** บนจอ 360px headline จะยาว 2–3 บรรทัด typography ช่วยไม่ได้ → ย้ายวลีนี้ไปเป็นหัวข้อย่อยแรกของ About หรือเป็น bullet ใน Hero
- **รับจาก Devil:**
  - R2 เลื่อน Guestbook ไป Later
  - R4 เพิ่มการ์ด "งานที่เคยทำ" 1 ใบ รูปแบบ ปัญหา → สิ่งที่ทำ → ผลลัพธ์ โดยไม่ระบุชื่อลูกค้า
  - R3 ใส่ microcopy ใต้ฟอร์ม "ใช้ข้อมูลนี้เพื่อตอบกลับคุณเท่านั้น"
  - About 2–3 ย่อหน้าก็พอ แต่ยังต้องแก้ L2
- **ค้าน R1:** ถ้าซ่อนอีเมล จะไม่เหลือช่องทางที่ใช้ได้แน่นอน → ใช้ลิงก์ `mailto` ที่ตัวลิงก์เขียนว่า "ส่งอีเมล" แทนการโชว์ที่อยู่
- **ค้าน R7 ที่ให้ใช้ GitHub แทนฟอร์ม:** HR และลูกค้าไม่ติดต่องานผ่าน GitHub → เสนอให้ซ่อนฟอร์มเมื่อ API ยังตอบ 501 แล้วใช้ปุ่ม "ส่งอีเมล" เป็น CTA หลัก (ถอนข้อเสนอ "หน้า 501 สวย ๆ")
- **ประนีประนอม R5:** เก็บ "ทำงานร่วมกับ AI agents" ไว้ แต่ให้อยู่ในบรรทัดรอง ไม่ใช่ข้อความเด่นของ Hero

## Devil's Advocate

### รอบ 1

| ID | ความเสี่ยง |
|---|---|
| R1 | Gmail ส่วนตัวแสดงเป็น plain text → bot เก็บไป → spam · ขัดกับข้อ "หลีกเลี่ยงข้อมูลส่วนตัว" ใน Brainstorm |
| R2 | Guestbook: การ escape กัน XSS ได้อย่างเดียว ยังไม่มี rate limit, honeypot, moderation หรือเพดานความยาว → spam หรือข้อความหมิ่นประมาทขึ้นบนเว็บที่มีชื่อจริง และ SQLite โตได้ไม่จำกัด |
| R3 | ฟอร์ม Contact เก็บชื่อและอีเมลของคนอื่น (PDPA) แต่ยังไม่มีระยะเวลาเก็บ วิธีลบ privacy notice หรือนโยบาย backup ของ volume |
| R4 | "5+ ปี" ไม่มี Portfolio รองรับ (ถูกเลื่อนไป Later) · LinkedIn ว่าง → คำเคลมลอยอยู่ ทั้งที่กลุ่มหลักคือ HR |
| R5 | "Full-stack" และ "เว็บนี้สร้างด้วย AI agents" ชวนให้ถามว่าเขียนเองแค่ไหน เว็บเป็น Astro ไม่ใช่ PHP และถ้าอธิบายต่อเสี่ยงพูดถึงคอร์ส |
| R6 | Audience 4 กลุ่ม ทำให้ข้อความไม่โดนใจใครเลย |
| R7 | ฟอร์มที่ตอบ 501 ตอน ship = CTA ที่ใช้ไม่ได้ |
| R8 | parser อ่าน Bio ได้แค่ย่อหน้าแรก หรือ FALLBACK ถูก render ออกสาธารณะ (L2) |

- **คำถามที่ต้องตอบก่อน ship:** จะโชว์ Gmail จริงไหม · ใคร moderate guestbook · เก็บข้อมูลจากฟอร์มกี่วันและลบอย่างไร · ถ้า HR ขอดูงาน 1 ชิ้นจะเปิดอะไรให้ดู · ถ้ายังได้ 501 จะซ่อนฟอร์มหรือโชว์ว่า "ยังไม่พร้อม" · ข้อความ AI agents ช่วยหรือทำร้าย credibility
- **ตัดหรือปรับใน Must:** ตัด "Contact 501 ต้องแสดงข้อความสวย" · ลด About เหลือ 2 ย่อหน้าที่คม · ใส่ Skills เฉพาะสิ่งที่พิสูจน์ได้ · ยก case study 1 ชิ้นขึ้นจาก Later · Guestbook เลื่อนไป Later จนกว่าจะมี rate limit และ moderation

### รอบ 2 (ตอบ Brand + UX)

- **ปิดแล้ว:**
  - R6: โฟกัส HR ตัดมือใหม่ออก
  - R7: ฟอร์มเก็บข้อความไว้และมีช่องทางสำรอง
  - R5 ครึ่งหนึ่ง: ตัด Full-stack แล้ว
- **ยังเปิดหรือแย่ลง:**
  - **R4/R5 overclaim จุดใหม่:** tagline "5+ ปี … ด้วย PHP · Laravel" อ่านแล้วเหมือนใช้ Laravel มา 5 ปี ซึ่งขัดกับ Bio ที่บอกว่า "กำลังขยายสู่ Laravel" → ควรเขียน "5+ ปี PHP · กำลังต่อยอด Laravel" · ข้ออ้างว่า "ตัวเว็บเป็นหลักฐาน" อ่อน เพราะเว็บเป็น Astro
  - **R1 แย่ลง:** ข้อเสนอ "อีเมลแสดงตลอด" ทำให้ Gmail อยู่ทุกหน้า → ใช้ alias หรือ obfuscate และให้เจ้าของยืนยัน
  - **R2:** แค่ย้ายไป footer ไม่ได้แก้ spam
  - **R3:** ยังไม่มีใครตอบเรื่องนโยบายเก็บข้อมูล
  - **R8:** ถ้าเรื่องเต็มจะไปอยู่ที่ About ยิ่งต้องแก้ L2 ก่อน
- **ใหม่ R9:** การประกาศ "เปิดรับงานประจำและฟรีแลนซ์" บนเว็บที่ใช้ชื่อจริง อาจกระทบนายจ้างปัจจุบัน → เจ้าของต้องยืนยันเองเท่านั้น
- **จุดยืน:** เห็นด้วยกับโครงเมนูและ Home สั้นของ UX และการโฟกัส HR ของ Brand แต่ยังไม่ควร ship จนกว่าจะครบ 4 ข้อ:
  1. เลือกวิธีแสดงอีเมล
  2. tagline ไม่เคลม Laravel 5 ปี
  3. Guestbook มี rate limit และ moderation หรือเลื่อนไป Later
  4. มี privacy notice ใต้ฟอร์ม
  - ขอให้ case study เป็น Must ถัดไป
